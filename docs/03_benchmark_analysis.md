# 2. 조회수가 높은 영상들의 공통 주제

## A. 누구나 바로 알아보는 음식

고조회 영상에 반복되는 소재:
- 카레라이스
- 햄버거 / 핫도그
- 라멘
- 케이크
- 초밥
- 피자
- 계란 요리
- 컬러 젤리
- 수박 디저트

핵심:
> 낯선 레시피보다 `이미 완성형을 머릿속에 알고 있는 음식`이 미니어처가 됐을 때 대비가 강하다.

우리 채널 우선 음식:
- 오므라이스
- 타코야키
- 라멘
- 계란말이
- 카레
- 편의점 주먹밥
- 야키토리
- 푸딩
- 스시
- 돈카츠

## B. 극단적 스케일 또는 숫자 제약

- 쌀 10알
- 계란 한 방울
- 1cm 스시
- 3cm 오므라이스
- 10엔 예산

숫자가 붙으면 시청자가 성공 여부를 즉시 이해한다.

## C. 눈에 보이는 변형

```text
투명 → 색이 생김
액체 → 굳음
반죽 → 부풀음
밋밋한 음식 → 화려한 장식
생재료 → 바삭한 완성품
```

단순 조리보다 `전/후 차이`가 큰 음식이 시각적 보상이 크다.

## D. 고양이에게 명확한 역할

- 식당 직원
- 요리사
- 배달원
- 시장 상인
- 손님 없는 가게 사장
- 야식 만드는 고양이

우리 채널에서는 이를 더 명확히 통일한다.

> 고양이는 작은 일본 마을의 요리사다.

# 3. 첫 3초 훅의 공통 패턴

## 패턴 1 — 설명 전에 바로 사건 시작

나쁜 예:
`今日はミニチュア料理を作ります。`

좋은 구조:
`猫の手に卵を渡した結果…`

## 패턴 2 — 말도 안 되는 제약

`卵、使うのは一滴だけ。`

화면과 문장이 동시에 `이게 가능해?`를 만든다.

## 패턴 3 — 미완성 문장

```text
その理由は・・・
できるかな？
大慌て！？
```

정답을 제목·초반에 닫지 않는다.

## 패턴 4 — 완성품은 짧게만 티저

```text
완성품 0.3~0.7초
→ 원재료
→ 제작 과정
```

또는 첫 영상처럼 완성품을 숨기고 결과를 끝까지 미룬다.

# 6. 콘텐츠 전개 방식

## 미니어처 요리 채널

```text
재료 등장
→ 자르기
→ 익히기
→ 조립/장식
→ 완성
```

시청 이유: 과정 자체의 만족감.

## AI 고양이 채널

```text
고양이에게 역할 부여
→ 일을 시작
→ 작은 문제 발생
→ 행동/실수
→ 해결 또는 웃긴 결말
```

시청 이유: 캐릭터에게 무슨 일이 생길지 궁금함.

## Tiny Cat Kitchen 하이브리드

```text
불가능해 보이는 미션
→ 작은 재료 공개
→ 조리
→ 실패 위기
→ 성공 직전
→ 캐릭터 반전
→ 다음 미션으로 루프
```

`米10粒でチャーハンは作れる？`

`破れたら全部やり直し。`

### FORMAT C — 고양이 식당 세계관
- 猫の小さなラーメン屋
- 猫の寿司屋
- 猫の深夜食堂

### FORMAT D — 선택/비교형
`1cm寿司 vs 3cm寿司`

### FORMAT E — 예상 밖 선택
완성품 대신:
- 파슬리
- 김 한 조각
- 빈 그릇
- 포장지
- 계산서
- 얼음

을 가져가 시그니처 개그화.

# 8. 빠르게 성장하는 영상들의 특징

1. 색 대비가 강함
2. 음식 이름을 몰라도 이해 가능
3. 조리가 아니라 `변신`처럼 보임
4. 결과 화면의 보상이 큼
5. 음소거로 봐도 이해됨
6. 한 영상에 목적 하나만 있음
7. 캐릭터의 목적과 사건이 명확함
8. 반복 가능한 세계관이 있음

피해야 할 것:
> 예쁘기만 한 45초. 반드시 문제·제약·위기·반전 중 최소 하나가 있어야 한다.

# 9. 경쟁자가 충분히 다루지 않은 빈틈

## GAP 1 — 일본 음식 + 고양이 + 극단적 숫자

```text
米10粒で猫がチャーハン
1滴の卵で卵焼き
10円で猫が夜食
```

## GAP 2 — 고양이의 작은 일본 생활세계

```text
새벽 시장
→ 재료 구매
→ 작은 식당 오픈
→ 주문
→ 요리
→ 설거지
→ 퇴근
```

## GAP 3 — ASMR 중심 AI 고양이

- 작은 칼 소리
- 쌀 볶는 소리
- 팬 지글거림
- 도자기 탁
- 발바닥 톡

## GAP 4 — 반복되는 캐릭터 성격

우리 고양이:
- 조금 성격 급함
- 요리는 의외로 잘함
- 완성 후 항상 이상한 것을 먼저 고름
- 실패 직전 앞발이 멈춤

## GAP 5 — 상품 제휴 가능한 미니 가젯

향후:
- 猫が一番小さいトースターを試す
- 猫のミニ炊飯器

# 10. 벤치마킹 기반 신규 Shorts 10개

## 1. 쌀 10알 볶음밥
**제목:** `米10粒でチャーハンは作れる？`  
**훅:** `今日使う米は、10粒だけ。`  
**구조:** 숫자 제한 → 한 알 떨어질 위기 → 완성 → 파 한 조각만 가져감.

## 2. 계란 한 방울 계란말이
**제목:** `卵1滴で卵焼きは作れる？`  
**훅:** `卵、これしか使いません。`  
**차별화:** 말기 과정 자체를 클리프행어로 사용.

## 3. 심야 고양이 라멘집
**제목:** `午前2時、猫のラーメン屋が開きました。`  
**훅:** `最初のお客さんが来ません。`  
**차별화:** 심야식당 세계관.

## 4. 1cm vs 3cm 스시
**제목:** `1cm寿司 vs 3cm寿司、難しいのはどっち？`  
**훅:** `小さい方が簡単だと思う？`

## 5. 10엔 야식 챌린지
**제목:** `猫に10円だけ渡したら何を作る？`  
**훅:** `今日の予算、10円です。``

## 6. 실패하면 문 닫는 타코야키집
**제목:** `1個失敗したら閉店する猫のたこ焼き屋`  
**훅:** `一個でも崩れたら、今日は閉店。`

## 7. 비 오는 날 우동집
**제목:** `雨の日、猫が小さなうどん屋を開きました。`  
**훅:** `お客さんは、まだ0人。`

## 8. 고양이 편의점 야식
**제목:** `猫が深夜のコンビニで選んだ3つ`  
**훅:** `最後だけ、絶対それじゃない。`

## 9. 미니 토스터 테스트
**제목:** `このトースター、本当に焼ける？猫が試します。`  
**훅:** `おもちゃに見えるけど…`

## 10. 댓글이 정한 메뉴
**제목:** `一番多かったコメントの料理を猫が作ります。`  
**훅:** `昨日、一番多かったのはこれ。`

# 11. 최종 벤치마킹 결론

복제해야 할 것은 음식이나 캐릭터 디자인이 아니라 **구조**다.

```text
Miniature Cooking의 강점
= 실제 질감 + 극단적 스케일 + 만족스러운 변형

AI 고양이 채널의 강점
= 목적 + 사건 + 캐릭터 + 반복 세계관

Tiny Cat Kitchen
= 둘을 합치되 일본 생활문화 + 숫자 도전 + ASMR + 반복 개그 추가
```

핵심 차별화:

> **Tiny Cat Kitchen은 미니어처 음식을 보여주는 채널이 아니라, 작은 일본 세상에서 고양이 요리사가 매일 새로운 문제를 해결하는 채널이다.**
