# 45초 Shorts 대본 · 훅 · 리텐션 구조

## 파일럿 제목

**猫の手で3cmオムライスは作れる？**

---

## 1. 기본 45초 대본

### 0~3초 — 훅

```text
これ、全部食べられます。
しかも、作るのは猫の手。
```

### 3~10초 — 궁금증

```text
今日作るのは…
3センチのオムライス。
こんな小さくて、本当に作れる？
```

### 10~18초 — 볶음밥

```text
まずは、ごはん。
たった一口分。
ケチャップをちょん。
猫の手で、まぜまぜ。
```

### 18~27초 — 계란

```text
次は、たまご。
ここが一番むずかしい。
破れたら、最初から。
そーっと…。
成功！
```

### 27~35초 — 완성

```text
ごはんに乗せて…。
ケチャップを一本。
できた。
世界一小さい？
猫のオムライス。
```

### 35~42초 — 반전

```text
じゃあ、猫が食べる？
……と思ったら。
食べるの、そこ！？
オムライス、完全スルー。
```

연출: 고양이 앞발이 오므라이스 대신 옆의 미니 파슬리를 가져간다.

### 42~45초 — CTA

```text
次、猫に何作ってほしい？
ラーメン？寿司？
コメントで決めて。
```

# 2. 첫 3초 훅 20개

## A. 궁금증 유발형

1. `これ、猫の手で本当に作れる？`
2. `3センチのオムライス、どうやって作ると思う？`
3. `この小さなフライパン、何ができると思う？`
4. `猫の手に卵を渡した結果…`
5. `最後だけ、ちょっとおかしいです。`

## B. 충격적인 사실형

6. `これ、ミニチュアじゃなくて本当に食べられます。`
7. `このオムライス、たった3センチです。`
8. `卵一滴でオムライスを作ります。`
9. `猫の手のほうが、私より料理上手でした。`
10. `こんな小さいのに、ちゃんとオムライスです。`

## C. 질문형

11. `猫がオムライスを作ったら、食べたい？`
12. `3センチのオムライス、成功すると思う？`
13. `このサイズの卵、破らず焼ける？`
14. `猫に料理させたら、何を作ると思う？`
15. `これ、最後まで失敗せず作れると思う？`

## D. 강력한 결과 약속형

16. `40秒後、世界一かわいいオムライスができます。`
17. `最後に、想像よりちゃんとした料理になります。`
18. `この小さな材料が、本物のオムライスになります。`
19. `最後の3秒だけは絶対見て。`
20. `この猫、40秒でオムライスを完成させます。`

# 3. 시청 지속률 최적화 버전

## 0~3초 — 강한 훅 + 미래 사건 예고

```text
猫の手に卵を渡した結果…
最後、まさかのものを選びます。
```

화면:
- 앞발 + 미니 달걀/계란볼 + 프라이팬 초근접
- 완성 음식은 숨김

## 3~7초 — 크기 반전

```text
作るのは、3センチのオムライス。
これ、本当に食べられます。
```

## 7~12초 — 재료의 극단적 양

```text
ごはんは、これだけ。
ケチャップも一滴。
でも問題は…卵。
```

화면:
- 쌀 약 10알
- 케첩 한 방울

## 12~15초 — 실패 조건 설정

```text
ここで破れたら…
全部やり直し。
```

## 15~18초 — 클리프행어

```text
あっ…。
これ、ヤバい。
```

연출:
- 계란 가장자리가 찢어질 듯한 순간
- 0.3~0.5초 정적

## 18~23초 — 첫 문제 해결 + 새 문제

```text
ギリギリ成功。
でも、本当に難しいのはここから。
```

## 23~28초 — 두 번째 실패 조건

```text
この卵を…
ごはんに乗せます。
一回でもズレたら終わり。
```

## 28~30초 — 거의 성공

```text
乗った。
あと一本。
```

## 30~34초 — 예상 밖 정보 / 새로운 오픈루프

```text
でも実は…
これ、猫が食べるためじゃありません。
```

목표:
- `그럼 누가 먹는데?`라는 두 번째 질문 발생

## 34~38초 — 완성 공개

```text
じゃあ、誰が食べるの？
その前に、完成。
```

## 38~42초 — 결말 반전

```text
猫が選んだのは…
そっち！？
オムライス、完全無視。
```

연출:
- 오므라이스 쪽으로 발 접근
- 오므라이스를 지나쳐 파슬리를 가져감

## 42~45초 — CTA + 루프

```text
次は何を作る？
ラーメン？寿司？
猫の手に卵を渡した結果…
```

마지막 화면:
- 고양이가 작은 계란/계란볼을 다시 첫 위치에 놓음
- 첫 프레임과 최대한 같은 구도

# 4. 리텐션 설계 공식

45초 전체를 하나의 긴 질문으로 끌지 않는다.

```text
0초: 이걸 고양이가 만든다고?
↓
7초: 이렇게 적은 재료로 가능해?
↓
12초: 계란이 안 찢어질까?
↓
18초: 살았는데, 다음 단계는?
↓
23초: 밥 위에 제대로 올릴 수 있을까?
↓
30초: 고양이가 먹는 게 아니라고?
↓
38초: 그럼 무엇을 선택하지?
↓
42초: 파슬리라고?
↓
45초: 다시 첫 질문으로 루프
```

핵심 원칙:

> **질문 → 부분 해결 → 더 큰 질문**을 5~8초마다 반복한다.

# 5. 편집 시 삭제할 요소

- 채널 인사
- 자기소개
- `오늘은 무엇을 만들어볼게요` 같은 느린 설명
- 같은 조리 동작을 2초 이상 반복
- 이미 화면에서 명확히 보이는 내용을 긴 문장으로 재설명
- 완성품을 초반에 너무 오래 공개
- `좋아요와 구독 부탁` 같은 일반적인 CTA

CTA는 다음 영상 메뉴 선택처럼 **콘텐츠에 직접 영향을 미치는 질문**으로 만든다.

예:

```text
次はラーメン？寿司？
```

# 6. 캐릭터 반복 개그 후보

고양이 캐릭터의 반복 행동을 만들면 IP 기억률이 높아진다.

1. 완성 음식보다 항상 장식 재료를 먼저 가져감
2. 중요한 순간에 앞발로 테이블을 톡 침
3. 요리가 실패할 것 같으면 발이 잠시 멈춤
4. 마지막에 다음 재료를 화면 중앙에 놓음
5. 아주 작은 재료를 보고 고개 대신 앞발만 천천히 가까이 댐

이 행동은 모든 영상에 전부 넣지 말고 1~2개씩 반복한다.
