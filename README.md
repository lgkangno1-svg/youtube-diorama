# Tiny Cat Kitchen — 일본 타깃 AI 미니어처 요리 Shorts 프로젝트

> 작성 기준일: 2026-08-24
> 상태: 기획 / Google Flow 제작 준비
> 타깃: 일본 10대·20대 중심, 글로벌 확장 가능
> 핵심 포맷: 고양이 앞발 × 디오라마 × 초미니 실제 음식 × ASMR × 짧은 스토리

## 현재 제작 표준 — 먼저 이것부터 적용

2026-08-24 최신 Loop 결과로 초기 파일럿 제작 표준을 아래처럼 갱신했다.

> **무료 keyframe preflight → Veo 3.1 Lite 최대 5 generations → 38~40초 편집 → 실패 컷만 재생성**

이유:
- 비구독 사용자는 하루 50개의 무료 Flow credits를 받음
- Veo 3.1 Lite는 비-Ultra 기준 generation당 10 credits
- 5 generations = 50 credits이므로 무료 일일 한도 안에서 파일럿 1편 전체 모션 테스트 가능
- 기존 6 generations 기본안 대비 약 17% 절감
- CTA/루프용 별도 영상은 만들지 않고 오프닝 keyframe을 재사용
- Flow 요청이 복수 generation을 만들 수 있으므로 output count는 항상 1로 확인
- keyframe/ingredient는 Flow의 무료 기본 이미지 모델 Nano Banana 2 Lite에서 먼저 검수

세부 운영 규칙은 `docs/06_zero_waste_flow_factory.md`를 현재 기준 문서로 사용한다.
기존 `docs/02_google_flow_scene_prompts.md`의 6장면 예시는 대본/연출 참고용이며, 실제 최초 생성 예산은 episode manifest의 5-generation 제한을 우선한다.

## 1. 프로젝트 목적

YouTube Shorts에서 조회수만 높은 채널이 아니라, 장기적으로 광고·YouTube Shopping·제휴·브랜드 협찬·캐릭터 IP 확장까지 가능한 쇼츠 채널을 만든다.

단순한 `귀여운 AI 고양이` 또는 `미니어처 요리` 복제가 아니라 아래 두 시장의 강점을 결합한다.

1. **미니어처 요리 채널의 만족감**
   - 실제 먹을 수 있어 보이는 초소형 음식
   - 작은 도구, 조리 소리, 질감, 매크로 촬영
   - 결과물이 완성되는 과정 자체의 시각적 보상
2. **AI 고양이 캐릭터 채널의 서사성**
   - 고양이에게 직업·미션·성격을 부여
   - 5~10초마다 작은 문제 또는 반전 발생
   - 반복 캐릭터와 세계관 형성

최종 포지셔닝:

> **「작은 세상에서 고양이가 매일 요리하고 살아가는 채널」**

요리에서 시작하지만 향후 미니 편의점, 작은 집, 카페, 캠핑, 여행, 가전, 쇼핑으로 세계관을 확장한다.

## 2. 지금까지의 질문·의사결정 순서

### STEP 1 — 돈 되는 Shorts 주제 탐색

요청:
- 유튜브 쇼츠로 수익화하기 좋은 주제 5개
- 시장 수요
- 경쟁 강도
- 예상 CPM/수익화 가능성
- 지속 제작 난이도
- 무자본 진입 난이도

검토한 방향:
1. 고양이 앞발 × 미니어처 가젯/제품 연구소
2. 고양이 앞발 × 초미니 요리 ASMR
3. 고양이 앞발 × 미니어처 방꾸미기
4. 고양이 앞발 × 수리·복원 ASMR
5. 고양이 앞발 × 여행 디오라마

결론:
- 장기 수익 최대화만 보면 **가젯/제품 연구소**가 강함.
- 첫 채널의 조회수, 반복 생산성, 글로벌 확장성까지 합치면 **초미니 요리 + 가젯 결합형**이 가장 좋음.
- 첫 브랜드 콘셉트를 `Tiny Cat Kitchen`으로 설정.

### STEP 2 — 45초 바이럴 Shorts 대본

첫 파일럿 주제:

> **고양이가 3cm 오므라이스를 만든다면?**

기본 구조:
- 0~3초 강력한 훅
- 3~10초 궁금증
- 10~35초 조리 과정
- 35~42초 반전
- 42~45초 댓글 CTA

### STEP 3 — 첫 3초 훅 20개 제작

4개 유형으로 5개씩 제작:
- 궁금증 유발형
- 충격적인 사실형
- 질문형
- 강력한 결과 약속형

최상위 훅:

> **「猫の手に卵を渡した結果…」**

서브 후보:
- 「これ、ミニチュアじゃなくて本当に食べられます。」
- 「3センチのオムライス、成功すると思う？」

### STEP 4 — 시청 지속률 중심으로 대본 재구성

핵심 원칙:
- 첫 3초에 완성품을 모두 노출하지 않음
- 5~10초마다 새로운 미해결 질문 생성
- 15초에 계란이 찢어질 듯한 클리프행어
- 30초에 새로운 오픈루프
- 마지막에 고양이가 오므라이스가 아닌 파슬리를 선택
- 마지막 프레임을 첫 프레임과 연결해 루프

### STEP 5 — 30일 콘텐츠 캘린더 제작

정보형 / 실험형 / 비교형 / 실수·주의형 / 논쟁형 / 사례형 / 리스트형 / 트렌드형을 섞어 30개를 설계.

초기 테스트 우선순위:
1. 3cm 오므라이스
2. 쌀 10알 볶음밥
3. 계란 한 방울 계란말이
4. 10엔 요리 챌린지
5. 비 오는 날 작은 우동집

### STEP 6 — Google Flow 제작 파이프라인

초기에는 45초 전체를 한 번에 만들거나 모든 장면을 Quality로 생성하지 않는다.

현재 표준:
- 무료 이미지 keyframe으로 캐릭터/주방/도구/스케일 사전 검수
- 동일 Reference Pack 고정
- Lite 최대 5 generations
- 약 38~40초 파일럿
- 실패 컷만 재생성
- Quality는 장기 재사용할 Hero asset에만 선택적으로 사용

### STEP 7 — 경쟁 채널 벤치마킹

주요 비교군:
- Miniature Cooking Ideas
- Miniature Space
- Miniature Hieu's Kitchen
- Tiny Cakes / Miniature Cooking 계열
- AI猫にゃんこちん Official

핵심 발견:
- 미니어처 요리 대형 채널은 **유명 음식 + 극단적으로 작은 크기 + 변형/완성 과정**에서 강함.
- 일본 AI 고양이 채널은 **고양이에게 직업/미션 부여 + 문제 발생 + 해결**이 강함.
- `고양이 캐릭터 서사 + 실제 먹을 수 있어 보이는 미니 요리 + 일본 생활세계`를 동시에 밀어붙이는 경쟁자는 상대적으로 약함.

## 3. 채널 운영 원칙

### 캐릭터
- 오렌지 태비 고양이
- 앞발 끝은 흰색 양말 무늬
- 실제 고양이 발의 형태를 유지
- 인간 손가락이나 엄지손가락이 생기지 않음
- 성격: 조금 급하지만 요리는 의외로 잘함
- 먹는 것에 호기심이 많지만 항상 예상과 다른 것을 선택

### 비주얼
- 9:16 세로
- 매크로 렌즈 느낌
- 얕은 심도
- 실제 음식 질감
- 일본의 아늑한 작은 주방
- 과도한 판타지보다 `실제로 존재할 법한 미니 세계`

### 사운드
- 프라이팬 지글거림
- 작은 나무 도마 소리
- 도자기·금속 조리도구의 작은 충돌음
- 고양이 발의 부드러운 탭
- 필요 시 아주 작은 고양이 울음
- 생성 단계에서는 일본어 화면 텍스트를 최소화하고 후편집 내레이션/자막 사용

### 금지 요소
- 인간 손 등장
- 고양이 발이 인간 손가락으로 변형
- 조리도구가 컷 사이에서 다른 물건으로 변함
- 재료가 갑자기 증식/소멸
- 음식 크기가 컷마다 달라짐
- 워터마크
- 화면 안의 깨진 일본어 AI 텍스트
- 불필요한 카메라 흔들림

### 원본성 가드
각 episode는 최소한 아래 3가지가 고유해야 한다.
- unique_goal
- unique_conflict
- unique_ending

동일 conflict + ending 조합은 다음 5편 안에 재사용하지 않는다.

## 4. 성공 지표

초기 30일은 구독자보다 다음을 우선 관찰한다.

1. Viewed vs Swiped Away
2. 평균 시청 지속 시간
3. 평균 시청률(%)
4. 1초 / 3초 / 15초 / 30초 잔존율
5. 반복 재생 신호
6. 댓글률
7. 저장·공유율
8. 음식별 성과
9. 스토리형 vs 순수 조리형 성과
10. 고양이가 실수하는 영상 vs 완벽하게 성공하는 영상 성과

목표는 30일 안에 `조회수가 잘 나오는 음식`만 찾는 것이 아니라 **우리 채널에서 반복 가능한 승리 포맷 2~3개**를 찾는 것이다.

## 5. 수익화 기준

2026년 확대 YPP 조기 진입 목표:
- 구독자 500명
- 최근 90일 공개 업로드 3회
- 최근 90일 qualified Shorts views 300만 또는 장문 qualified watch hours 3,000

현재 광고/Premium 목표:
- 구독자 1,000명
- 최근 90일 qualified public Shorts views 1,000만 또는 qualified watch hours 4,000

2027-02-01부터 신규 광고/Premium 진입은 1,000명 + 2,000만 qualified Shorts views/90일 또는 8,000 watch hours로 강화 예정.

500명 단계에서 타 브랜드 YouTube Shopping Affiliate가 자동 활성화된다고 가정하지 않는다. 실제 Studio 자격을 확인한 뒤 사용한다.

포토리얼한 AI Tiny Cat Kitchen 영상은 실제로 일어나지 않은 사실적 장면이므로 YouTube Studio의 AI use disclosure를 기본적으로 `Yes`로 처리한다. 공개 자체는 추천 또는 수익화 자격을 제한하지 않는다.
